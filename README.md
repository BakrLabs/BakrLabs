# Hi, I'm Mohamed

I'm an independent developer building under the name BakrLabs. I like making software that does one job well, whether that's a tool for the terminal, a website, or an app on your phone. Most of my code gets written on my phone.

## What I build

- **Command-line and automation tools** in Rust: fast, dependency-light programs that run without setup or accounts.
- **Engineering and science tools**: calculators, simulators, and planners for physics, aerospace, and other technical work, where the numbers have to be right.
- **Websites and landing pages**: clean, responsive sites, including Arabic and bilingual ones.
- **Android apps** in Kotlin and Rust.
